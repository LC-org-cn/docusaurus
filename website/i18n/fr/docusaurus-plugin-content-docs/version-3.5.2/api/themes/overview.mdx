# Thèmes Docusaurus

Nous fournissons des thèmes officiels de Docusaurus.

## Thèmes principaux {/* #main-themes */}

Les principaux thèmes implémentent l'interface utilisateur pour les extensions [docs](../plugins/plugin-content-docs.mdx), [blog](../plugins/plugin-content-blog.mdx) et [pages](../plugins/plugin-content-pages.mdx).

- [@docusaurus/theme-classic](./theme-classic.mdx)
- 🚧 d'autres thèmes sont prévus

:::warning

L'objectif est de faire en sorte que tous les thèmes partagent exactement les mêmes fonctionnalités, la même expérience utilisateur et la même configuration.

Seuls la conception de l'interface utilisateur et le framework de style sous-jacent doivent changer, et vous devez pouvoir changer de thème facilement.

Nous n'en sommes pas encore là : seul le thème classic est prêt pour la production.

:::
