# Déploiement sur Vercel

Déployer votre projet Docusaurus sur [Vercel](https://vercel.com/) vous fournira [différents avantages](https://vercel.com/) dans les domaines de la performance et de la facilité d'utilisation.

Pour déployer votre projet Docusaurus avec un [Vercel pour l'intégration Git](https://vercel.com/docs/concepts/git), assurez-vous qu'il a été poussé dans un dépôt Git.

Importez le projet dans Vercel en utilisant [Import Flow](https://vercel.com/import/git). Lors de l'importation, toutes les options pertinentes sont préconfigurées pour vous; toutefois, vous pouvez choisir de modifier n'importe laquelle de ces [options](https://vercel.com/docs/build-step#build-&-development-settings).

Après l'importation de votre projet, tous les pushs ultérieurs vers les branches généreront des [Déploiements d'aperçu](https://vercel.com/docs/platform/deployments#preview), et toutes les modifications apportées à la [Branche de production](https://vercel.com/docs/git-integrations#production-branch) (communément « main » ou « master ») donneront lieu à un [Déploiement de production](https://vercel.com/docs/platform/deployments#production).
