# 📦 theme-mermaid

Ce thème fournit un composant `@theme/Mermaid` propulsé par [mermaid](https://mermaid-js.github.io/). Vous pouvez en lire plus sur la documentation des [diagrammes](../../guides/markdown-features/markdown-features-diagrams.mdx).

```bash npm2yarn
npm install --save @docusaurus/theme-mermaid
```

## Configuration {/* #configuration */}

```js title="docusaurus.config.js"
export default {
  themes: ['@docusaurus/theme-mermaid'],
  // In order for Mermaid code blocks in Markdown to work,
  // you also need to enable the Remark plugin with this option
  markdown: {
    mermaid: true,
  },
};
```
