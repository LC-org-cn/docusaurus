# Temas Docusaurus

Nós fornecemos temas oficiais do Docusaurus.

## Temas principais {/* #main-themes */}

The main themes implement the user interface for the [docs](../plugins/plugin-content-docs.mdx), [blog](../plugins/plugin-content-blog.mdx) and [pages](../plugins/plugin-content-pages.mdx) plugins.

- [@docusaurus/theme-classic](./theme-classic.mdx)
- 🚧 other themes are planned

:::warning

O objetivo é que todos os temas compartilhem exatamente os mesmos recursos, experiência do usuário e configuração.

Apenas o design da IU e a estrutura de estilo subjacente devem mudar, e você deve ser capaz de alterar o tema facilmente.

Ainda não chegamos lá: apenas o tema clássico está pronto para produção.

:::
